WaFine يعتمد مبدأ الـ open-core. الخدمة المُدارة هي أسهل طريقة لاستخدامه، لكن المكونات نفسها
يمكن أن تعمل على بنيتك التحتية الخاصة. هذه الصفحة نظرة عامة، وليست دليل تثبيت.

## المكونات

| المكوّن | الدور |
|---|---|
| [OpenWA](https://github.com/rmyndharis/OpenWA) | محرك واتساب: عميل واتساب غير رسمي ومفتوح المصدر، يدير جلسات الأجهزة المرتبطة ويوفر واجهة REST وخادم MCP. |
| الـ Backend لملف الواجهة (BFF) | طبقة الواجهة العامة: التسجيل والدخول، الجلسات ومفاتيح API لكل مستخدم، حصة الإرسال، الردود التلقائية المضبوطة الإيقاع، وميزة OAuth لعملاء MCP مثل Claude. |
| تطبيق الويب | لوحة التحكم التي يربط بها المستخدمون واتساب برمز QR، ويديرون المفاتيح والتطبيقات المتصلة، ويشغلون الـ Workflows أو يوقفونها. |
| Postgres | الحسابات والمفاتيح وبيانات الجلسات وسجلات الرسائل. |
| مخزن كائنات متوافق مع S3 | ملفات الوسائط والنسخ الاحتياطية، محفوظة بخصوصية وتُقدَّم عبر روابط قصيرة الأجل. |

## كيف تتراكب القطع

```text
users and agents ──HTTPS──▶ BFF ──▶ OpenWA ──▶ WhatsApp
                             │         │
                             ▼         ▼
                          Postgres   object store
```

- الـ BFF وحده هو المكشوف على الإنترنت. الـ OpenWA يبقى على شبكة خاصة.
- يحتفظ الـ BFF بمفتاح المدير (admin key) للمحرك، ويُصدِر لكل مستخدم مفتاحاً محصوراً بجلسته
  الخاصة.
- حالة جلسة واتساب تعيش على وحدة تخزين المحرك نفسها (volume). عاملها كبيانات دخول
  (credential) وشفّر نسخها الاحتياطية.

## ما الذي تحتاج إليه

- خادم Linux قادر على تشغيل الحاويات.
- قاعدة Postgres.
- مخزن (bucket) متوافق مع S3 للوسائط والنسخ الاحتياطية.
- نطاق لتطبيق الويب وللـ API، مع TLS.
- رقم واتساب يتبع الإرشادات في صفحة [استخدام واتساب](/ar/using-whatsapp).

## ما يجب حسمه قبل البدء

- **مكان البيانات.** اختر أين تعمل القاعدة والوسائط والمحرك، واقرأ ما تقوله قوانين حماية
  البيانات في بلدك عن التنقل بينها.
- **العرض.** أبقِ المحرك خاصاً، ولا تنشر إلا الـ BFF.
- **حدود الإرسال.** أبقِ الإيقاع مفعلاً وحدد حصة إرسال متحفظة لكل رقم.
