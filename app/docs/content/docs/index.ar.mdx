WaFine خدمة مُدارة تحوّل رقم واتساب تملكه أصلًا إلى شيء يمكن لبرمجياتك ومساعدك الذكي
استخدامه. تربط الرقم مرة واحدة بمسح رمز QR، ثم تناديه من السكربتات أو التطبيقات أو Claude.

WaFine مبني على [OpenWA](https://github.com/rmyndharis/OpenWA)، وهو عميل واتساب
**غير رسمي**. ليس مرتبطًا بـ WhatsApp أو Meta ولا معتمدًا منهما. اقرأ
[استخدام واتساب](/ar/using-whatsapp) قبل ربط أي رقم.

## ماذا تحصل عليه

- **جلسة واتساب مرتبطة.** جلسة واحدة لكل حساب، مرتبطة بالرقم الذي دُخِّلت إليه.
- **واجهة REST.** ترسل الرسائل وتقرأ محادثاتك عبر HTTPS بمفتاح API شخصي.
- **مفاتيح API تتحكم بها.** حتى خمسة مفاتيح نشطة، كلٌّ منها محدود بجلستك فقط، وتحذفه متى
  شئت.
- **نقطة اتصال MCP.** تدع Claude، أو أي عميل MCP، يقرأ محادثاتك ويرسل رسائل بالنيابة عنك.
- **ردود تلقائية مضبوطة الإيقاع.** قواعد مدمجة بسيطة تجيب متصلك المعروفين بتوقيت يشبه
  الإنسان.

## كيف يعمل

1. تطلب دعوة. الدخول بالدعوة فقط ما دامت الخدمة في الإصدار المبكر.
2. تسجّل برقم واتساب الذي وصلت إليه الدعوة.
3. تربط ذلك الرقم بمسح رمز QR من WhatsApp في هاتفك.
4. إنشاء مفتاح API وتبدأ نداء الواجهة، أو تربط Claude.

WaFine يجعل جلسة واتساب تعمل على خادمه، فلا يحتاج هاتفك أن يبقى متصلًا حتى تعمل الواجهة.

## أين تسكن بياناتك

- بيانات الحساب والمفاتيح ورسائل الحساب: قاعدة Postgres في الاتحاد الأوروبي (باريس).
- ملفات الوسائط: تُخزّن بخصوصية بالاتحاد الأوروبي وتُعرض لك فقط عند تسجيل الدخول.
- جلسة واتساب نفسها: خادم WaFine في المغرب.
