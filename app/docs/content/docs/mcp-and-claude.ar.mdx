يعرض WaFine جلستك كخادم MCP، حتى يقرأ مساعد مثل Claude محادثاتك ويرسل رسائل نيابة عنك.
نقطة الاتصال هي:

```text
https://api.example.com/mcp
```

هذا عنوان تجريبي: استبدل النطاق بـ **نقطة اتصال MCP** المعروضة في تطبيق الويب.

تستخدم نقل Streamable HTTP. يجب أن توجد جلسة واتساب وتكون متصلة أولًا.

## إضافة موصل Claude

يعمل هذا في Claude على الويب وتطبيقات سطح المكتب والهاتف. يدخل Claude بميزة OAuth، فلن تلصق
مفتاح API.

1. على خطة Claude شخصية (Free أو Pro أو Max)، افتح **Customize** ثم **Connectors**.
   وعلى خطة Team أو Enterprise، يضيف مسؤول المؤسسة الموصل أولًا؛ انظر إعدادات الموصلات في
   Claude لهذه الحالة.
2. اختر **Add** ثم **Add custom connector** (إضافة موصل مخصص).
3. أدخل الرابط `https://api.example.com/mcp` واترك خانات OAuth فارغة؛ يكتشف Claude رابط
   الدخول بنفسه.
4. أضف الموصل واستعمله في محادثة: انقر زر **+** في الدردشة، اختر **Connectors**، وفعّله.
5. اطلب مثلًا: «لخّص محادثات واتساب غير المقروءة.» تفتح صفحة WaFine أول مرة: سجّل دخولك،
   راجع الطلب، اختر **Allow** (السماح).

للقطع، انزع التطبيق من **Connected apps** (التطبيقات المتصلة) في صفحة **WhatsApp** في
WaFine، أو انزع الموصل من Claude. حذف جلستك يفصل كل التطبيقات أيضًا.

## استخدام مفتاح API بدلاً منه

العملاء الذين لا يقدرون على الدخول بميزة OAuth، مثل Claude Code أو وكيل مخصص، يمكنهم إرسال
مفتاح API في ترويسة `X-API-Key`.

Claude Code:

```bash
claude mcp add --transport http whatsapp https://api.example.com/mcp \
  --header "X-API-Key: <your-key>"
```

إعداد عميل MCP عام:

```json
{
  "mcpServers": {
    "whatsapp": {
      "type": "http",
      "url": "https://api.example.com/mcp",
      "headers": { "X-API-Key": "<your-key>" }
    }
  }
}
```

## القراءة فقط مقابل الإرسال

يقدّم خادم MCP في WaFine نوعين من الأدوات:

- **أدوات القراءة:** عرض المحادثات، قراءة الرسائل، البحث عن جهات الاتصال. لا تُحسب من حصة
  إرسالك أبدًا.
- **أدوات الإرسال:** إرسال الرسائل والرد عليها وإعادة توجيهها. تُحسب من حصة جلستك، مثل
  إرسال REST.

لا يعطي WaFine مفتاح قراءة فقط. لتُبقي المساعد للقراءة فقط، أطفئ أدوات الإرسال من صلاحيات
الأدوات في عميلك؛ وفي Claude اضبطها من إعدادات الموصل. إذا سمحت بالإرسال، أبقِ المصادقة
مفعلة حتى تؤكد كل رسالة قبل خروجها.

عند استهلاك حصة الإرسال، تعيد أدوات الإرسال خطأً يمكن لـ Claude العرض عليك، بدل فشل صامت.

## ممارسات جيدة

- اطلب من المساعد صياغة رد، ثم وافق على الإرسال بنفسك.
- لا تطلب منه مراسلة من لا يتوقع أن يسمع منك.
- اقرأ [استخدام واتساب](/ar/using-whatsapp) للإرشادات المرتبطة بخطر الحظر التي تشمل كل إرسال،
  مَن صدر عنه.
