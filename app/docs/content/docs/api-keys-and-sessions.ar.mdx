title: مفاتيح API والجلسات

لحساب WaFine جلسة واتساب واحدة. تتيح المفاتيح لبرمجياتك وتطبيقاتك استخدام تلك الجلسة عبر
HTTPS.

## الجلسات

- لكل حساب **جلسة واحدة**، مرتبطة بالرقم الذي سجّلت به.
- أنشئها وأعد ربطها برمز QR عند الحاجة، من صفحة **WhatsApp** في تطبيق الويب.
- **حذف الجلسة يلغي كل المفاتيح** المرفقة بها.

يمكنك عرض جلستك، لقراءة معرّفها وحالتها مثلًا:

```bash
curl "https://api.example.com/wa/sessions" -H "X-API-Key: <your-key>"
```

## إنشاء مفتاح

1. افتح صفحة **WhatsApp** في تطبيق الويب. يجب أن توجد جلستك أولًا.
2. أنشئ مفتاح API.
3. انسخه فورًا. تعرضه WaFine مرة واحدة فقط وتحفظ بصمته (hash) فقط.

يمكنك أن يكون لديك **خمسة مفاتيح نشطة** على الأكثر. ألغِ مفتاحًا لإنشاء آخر. استخدم مفتاحًا
منفصلًا لكل تطبيق أو جهاز، حتى تلغي واحداً دون أن يتعطل البقية.

## نطاق المفتاح

كل مفتاح محصور بـ **جلستك أنت فقط**:

- يمكنه قراءة محادثاتك ورسائلك وإرسال رسائل من رقمك.
- لا يمكنه رؤية جلسات المستخدمين الآخرين، ولا تغيير إعدادات الخادم، ولا حذف جلستك.
- يخضع لحصة إرسال جلستك (راجع [استخدام واتساب](/ar/using-whatsapp)).
- محدود في السرعة، افتراضيًا بـ 120 نداء في الدقيقة.

تعامل مع المفتاح ككلمة مرور. أبعده عن مستودعات الكود والمحادثات ولقطات الشاشة. إذا تسرب
مفتاح، ألغِه من صفحة **WhatsApp**.

## إرسال رسالة

أرسل المفتاح في ترويسة `X-API-Key`. معرّف المحادثة هو الرقم بالصيغة الدولية بدون `+`،
متبوعًا بـ `@c.us`.

```bash
curl -X POST "https://api.example.com/wa/sessions/<session-id>/messages/send-text" \
  -H "X-API-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{"chatId":"2126XXXXXXXX@c.us","text":"Your order is ready for pickup."}'
```

فوق الحصة تجيب الواجهة بـ `429` مع ترويسة `Retry-After`. انتظر قبل أن تعيد المحاولة.

## قراءة الرسائل

اعرض محادثاتك:

```bash
curl "https://api.example.com/wa/sessions/<session-id>/chats" \
  -H "X-API-Key: <your-key>"
```

اقرأ آخر رسائل محادثة واحدة:

```bash
curl "https://api.example.com/wa/sessions/<session-id>/messages?chatId=2126XXXXXXXX@c.us&limit=20" \
  -H "X-API-Key: <your-key>"
```

القراءات لا تُحسب من حصة إرسالك. وللوسائط في الرسائل لا رابط عام: الملفات تبقى في خانة
خاصة، ولا يمنح WaFine مفتاحك إلا روابط مؤقتة (لمدة لا تتجاوز ساعة على الأكثر) على ملفات
جلستك الخاصة.

## إلغاء مفتاح

افتح صفحة **WhatsApp** وألغِ المفتاح. يتوقف عن العمل فوراً.
