يمر هذا البرنامج التعليمي بالمسار كله مرة واحدة: حساب، رقم مرتبط، مفتاح API، رسالة اختبار،
رد تلقائي يجيب بنفسه، وClaude يقرأ محادثاتك. تحتاج هاتفًا فيه واتساب، وبريدًا إلكترونيًا،
وطرفية فيها `curl`.

## 1. اطلب دعوة

WaFine بالدعوة فقط. انضم إلى قائمة الانتظار على موقع WaFine ببريدك وبالرقم الذي تعتزم
استخدامه. استخدم رقمًا مخصصًا شغّالاً، لا رقمك الشخصي الذي لا يمكنك الاستغناء عنه (راجع
[استخدام واتساب](/ar/using-whatsapp)).

## 2. سجّل

حين تُوافق الدعوة، افتح تطبيق الويب واختر **Sign up** (التسجيل). أدخل بريدك، وكلمة مرور،
والرقم المدعو بالصيغة الدولية، مثلًا `+212 6XX XX XX XX`. أكّد بريدك من الرسالة التي تصل، ثم
ادخل إلى حسابك.

## 3. اربط واتساب برمز QR

1. افتح **WhatsApp** في تطبيق الويب وأنشئ جلستك.
2. على هاتفك، افتح واتساب، ادخل **الأجهزة المرتبطة**، اختر **ربط جهاز** ومسح رمز QR.
3. انتظر حتى تظهر الجلسة متصلة.

امسح بالرقم الذي سجّلت به؛ أي رقم آخر يُسجَّل خروجه.

## 4. أنشئ مفتاح API

في صفحة **WhatsApp**، أنشئ مفتاح API وانسخه فورًا: يُعرض مرة واحدة فقط. تعرض الصفحة
نفسها **معرّف جلستك**، وعنوان **REST الأساسي**، و**نقطة اتصال MCP**.

## 5. أرسل رسالة اختبار

راسل نفسك أو شخصًا ينتظر الرسالة. معرّف المحادثة هو الرقم بدون `+` أو مسافات، متبوعًا بـ
`@c.us`.

في كل أمر أدناه، استبدل `https://api.example.com` بعنوان REST الأساسي المعروض في تطبيق
الويب (خطوة 4)، و`<session-id>` و`<your-key>` بقيمك أنت.

```bash
curl -X POST "https://api.example.com/wa/sessions/<session-id>/messages/send-text" \
  -H "X-API-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{"chatId":"2126XXXXXXXX@c.us","text":"Hello from WaFine"}'
```

`429` مع `Retry-After` يعني أن حصة الإرسال للجلسة استُهلكت؛ انتظر قبل الإعادة.

## 6. شغّل ردًا تلقائيًا مضبوط الإيقاع

1. افتح **Workflows** في تطبيق الويب. كل القواعد مطفأة بدايةً.
2. شغّل **Ping**.
3. من متصلك في القائمة المسموحة، أرسل `ping` إلى رقمك.

بعد ثوانٍ، مع تأخير قراءة وطباعة قصير، يجيب WaFine بـ `pong`. فعّل **Greeting** (التحية) أيضًا
إن أردت إجابة أولى مهذبة لـ `hello` أو `salam` أو `bonjour`، مرة واحدة على الأكثر لكل
متصلك في اليوم. الردود التلقائية لا تجيب المجموعات ولا الوسائط ولا أرقامًا مجهولة. راجع
[Workflows](/ar/workflows) لقواعد الإيقاع.

## 7. اربط Claude عبر MCP

1. على خطة Claude شخصية، افتح **Customize** ثم **Connectors**، واختر **Add custom
   connector** (خطط Team وEnterprise: يضيف مسؤول المؤسسة الموصل أولًا — انظر إعدادات
   الموصلات في Claude).
2. أدخل نقطة اتصال MCP من تطبيق الويب (تشبه `https://api.example.com/mcp`) واترك خانات
   OAuth فارغة.
3. أضف الموصل. تفتح صفحة WaFine أول مرة تستعمله: سجّل دخولك إلى WaFine واختر **Allow** (سماح).
4. في محادثة، انقر زر **+**، اختر **Connectors**، فعّل الموّصل واطلب: «لخّص محادثات واتساب
   غير المقروءة ديالي.»

Claude Code يستخدم مفتاح API بدلاً من الدخول:

```bash
claude mcp add --transport http whatsapp https://api.example.com/mcp \
  --header "X-API-Key: <your-key>"
```

اترك المصادقة مفعّلة لأدوات الإرسال حتى تؤكد كل رسالة قبل خروجها.
