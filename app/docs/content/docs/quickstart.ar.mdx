لديك الدعوة والحساب (وإلا فإن صفحة [البدء](/ar/getting-started) تشرح التسجيل أولًا). كل ما
يلي يحدث في صفحة **WhatsApp** في تطبيق الويب، وتحتاج طرفية (terminal) فيها `curl`.

## 1. اربط رقمك

1. في صفحة **WhatsApp**، أنشئ جلستك. يظهر رمز QR.
2. على هاتفك، افتح واتساب، ادخل إلى **Linked devices** (الأجهزة المرتبطة)، اختر **Link a
   device** وامسح الرمز.
3. انتظر حتى تظهر الجلسة متصلة. الرقم الذي تمسح به يجب أن يكون رقم التسجيل نفسه.

## 2. أنشئ مفتاح API

في صفحة **WhatsApp** نفسها، أنشئ مفتاح API وانسخه فورًا — يُعرض مرة واحدة فقط ويحتفظ
WaFine فقط بصيغة hash منه.

## 3. أرسل رسالة

تعرض الصفحة نفسها **معرّف جلستك** و**عنوان REST الأساسي**. املأ القيمتين ورقم المستلم
(بالصيغة الدولية بلا `+` ثم `@c.us`):

```bash
curl -X POST "https://api.example.com/wa/sessions/<session-id>/messages/send-text" \
  -H "X-API-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{"chatId":"2126XXXXXXXX@c.us","text":"Hello from WaFine"}'
```

أرسل لنفسك أو لمن يتوقع رسالتك. جواب `429` يعني أنك بلغت حصة الإرسال: انتظر مهلة
`Retry-After` ثم حاول ثانية.
