## Agent-to-Agent (A2A) and Agent Network Protocol (ANP)

- **A2A Protocol Specification** — <https://github.com/a2a-protocol/A2A> — The core protocol for agent-to-agent communication. JSON-RPC 2.0 over HTTP, task lifecycle, artifacts, streaming.
- **ANP (Agent Network Protocol)** — <https://github.com/agent-network-protocol/ANP> — Decentralized agent discovery and communication. DID-based identity, P2P transport options.
- **A2A JavaScript SDK** — <https://www.npmjs.com/package/@a2a-js/sdk> — Client and server helpers for TypeScript/Node.
## Model Context Protocol (MCP)

- **MCP Specification** — <https://modelcontextprotocol.io/specification/2025-06-18> — Tools, resources, prompts, sampling. OAuth 2.1 authorization for remote servers.
- **MCP TypeScript SDK** — <https://www.npmjs.com/package/@modelcontextprotocol/sdk> — Official SDK for clients and servers.
- **Claude Connector Requirements** — <https://claude.com/docs/connectors/building/authentication> — OAuth 2.1, DCR, PKCE S256, allowed redirect URIs.
- **Our MCP implementation** — `docs/10-claude-connector.md` — BFF as OAuth 2.1 authorization server, opaque tokens, sealed engine keys, refresh rotation.

## WhatsApp Automation Risk

- **OpenWA** — <https://github.com/rmyndharis/OpenWA> — The engine WaFine builds on. MIT license. Arm64 Chromium, docker-proxy optional, `POSTGRES_SCHEMA` support.
- **WhatsApp Business API (Official)** — <https://developers.facebook.com/docs/whatsapp> — Cloud API pricing, conversation categories, template approval, partner programme.
- **WhatsApp Automation Ban Patterns** — No single authoritative source. Community knowledge: burst sends, identical templates, no human-like gaps, new number + high volume = high ban risk. WaFine's pacing (gap + daily cap) reduces risk; does not remove it.
- **Moroccan Law 09-08 / CNDP** — <https://www.cndp.ma/> — Personal data protection. International transfer to Paris (Supabase eu-west-3) is a transfer under 09-08 (risk R10). We describe where data lives; we do not certify compliance.
