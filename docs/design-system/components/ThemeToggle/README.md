# ThemeToggle
A square ghost icon button that flips between `wafine-light` and `wafine-dark`.

Source: `src/components/theme-toggle.tsx` (state from `theme-provider.tsx`).

- Shows the moon in light, the sun in dark (18px icons). 48px square.
- `aria-label` names the action: "Switch to dark theme" / "Switch to light theme".
- Lives in the app header and the top-right of auth screens.
