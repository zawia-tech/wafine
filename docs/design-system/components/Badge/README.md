# Badge
A small pill for counts, step numbers and session status.

Live primitive: `app/web/src/components/ui/badge.tsx`; used for the hero cadence label and connector step numbers.

- **Props:** `variant` (`secondary` default, `primary`, `neutral`, `outline`) and `size` (`md` default, `sm`, `lg`).

- Radius `rounded-badge`. `badge-sm` (12px) inside tables.
- Status badges always say the state in words ("Connected", "Pending", "Revoked"); colour is secondary.
