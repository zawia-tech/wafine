The UI icons used in the web app, extracted verbatim from inline SVG (app-header, theme-toggle, faq). 24×24 grid, stroke-width 2, round caps, no fill.

In code they use `stroke="currentColor"`; these files bake the light-theme ink `base-content` (`#1a202c`) because an `<img>` cannot inherit colour. Render them inline in product code at 16–20px.
